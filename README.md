# Personal Finance Tracker

A fully responsive and interactive Personal Finance Tracker web application developed using HTML, CSS, JavaScript, and Chart.js. This project helps users manage their daily expenses, set monthly budgets, visualize spending patterns through charts, and monitor financial activities efficiently.

The application provides a modern dashboard interface with dark/light mode support, responsive design, authentication system, expense search functionality, and real-time expense tracking. It is designed to improve personal financial management with a simple and user-friendly experience.

## Features

* User Login and Signup System
* Add and Delete Expense Records
* Monthly Budget Management
* Budget Remaining Calculation
* Expense Breakdown Pie Chart
* Monthly Expense Report Bar Chart
* Expense Search Functionality
* Dark and Light Mode
* Responsive Dashboard Design
* Local Storage Data Management
* Interactive and Modern User Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Chart.js
* Local Storage API

## Project Objective

The main objective of this project is to help users monitor and control their expenses effectively by providing a visual and organized financial tracking system. It also demonstrates frontend development concepts such as responsive web design, DOM manipulation, local storage handling, authentication, and chart integration.
